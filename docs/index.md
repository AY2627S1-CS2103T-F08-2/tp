**LaiNurse is a desktop application that gives home nurses fast access to patient and appointment details for home visits.** While it has a GUI, most of the user interactions happen using a CLI (Command Line Interface).

* If you are interested in using LaiNurse, head over to the [_Quick Start_ section of the **User Guide**](UserGuide.html#quick-start).
* If you are interested in developing LaiNurse, the [**Developer Guide**](DeveloperGuide.html) is a good place to start.
